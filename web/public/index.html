How it works

Three hops, by default all inside your home

  1. 1

    You speak

    The Voice PE hears its wake word on the device and streams your question to Home Assistant.

  2. 2

    Home Assistant listens

    Its Assist pipeline turns speech into text and hands it to the Companion voice bridge over Wyoming.

  3. 3

    Your Companion answers

    Your local model answers with what Companion Memory knows about you, and the reply is spoken back.

Keep Home Assistant's own Whisper and Piper for speech, or let Companion handle speech too. Nothing leaves the house unless you choose it: cloud speech sends audio to OpenAI, and a model tag that starts with openai: sends your questions, and the memory an answer draws on, to OpenAI.

Help

        
When something is off

        

          

            Home Assistant cannot connect
            
Wyoming is plain TCP, not a web address. Enter only the IP and port 10700, and check that no firewall blocks it. From the Home Assistant host, nc -vz <ip> 10700 should succeed.

          

          

            The Voice PE lights up but never answers
            
Run the check. A red language model row usually means the model is still downloading or was never pulled: docker compose -f compose.yml exec ollama ollama pull llama3.2.

          

          

            Speech-to-text returns nothing
            
With fully local voice, download the speech models once (the two curl lines in Start it). With the simplest setup, choose faster-whisper and Piper in the assistant instead of the companion ones.

          

          

            Answers do not use my memory
            
The key needs the memory scope, and the address must end in /api when you reach Companion Memory through its gateway. The check shows the exact error.

          

          

            The check here fails but curl works
            
Browsers block an https page from calling a plain http address on your network. Serve ci-server over https with Tailscale Serve or a Cloudflare Tunnel, or trust the curl result.
